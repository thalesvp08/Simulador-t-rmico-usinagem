# No que consiste o trabalho
Meu programa simula um tarugo de 200mm de comprimento e 50mm de diâmetro sendo torneado, de modo que como o calor de corte nunca é igual se repete essa simulação 500x, cada uma com uma pequena variação aleatória, o chamado método de Monte Carlo. No final, o código mostra a porcentagem de vezes que essas repetições passaram do limite, estabelecendo que é uma operação segura aquela com risco abaixo de 15%, risco moderado entre 15% e 50% e risco alto acima disso .
# O que foi usado
 NumPy
 Streamlit
 Phyton
 Seaborn
 Matplotlib
## Como executar
1. Instalar as dependências: `pip install -r requirements.txt`
2. Rodar o app: `python -m streamlit run Trabalho_finalc2.py`
