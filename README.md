# Simulador de Risco Térmico na Usinagem
Aplicação em Python (POO, NumPy/Monte Carlo, Streamlit e Seaborn) para estimar o risco de superaquecimento no torneamento cilíndrico de Poliamida, Acrílico e Alumínio.

## Como executar
1. Instale as dependências: `pip install -r requirements.txt`
2. Rode o app: `python -m streamlit run Trabalho_finalc2.py`
